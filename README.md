# 🤖 Simple Chatbot

A basic Python chatbot that replies to user input using simple rules or intent-based logic.

---

## 📦 Features

* Text-based interaction via command line
* Rule-based logic to identify intent
* Easily extendable for more use cases
* Beginner-friendly Python structure

---

## 🛠️ Requirements

* Python 3.x
* No external libraries required

---

## 📂 Project Structure

```
simple_bot/
├── simple_chatbot.py   # Main chatbot script
├── README.md           # Project documentation
└── venv/               # (Optional) Virtual environment
```

---

## 🧪 How to Run

### 🖥️ On Windows

```bash
# Navigate to the project folder
cd path\to\simple_bot

# (Optional) Activate virtual environment
venv\Scripts\activate

# Run the chatbot
python simple_chatbot.py
```

### 🐧 On macOS/Linux

```bash
cd path/to/simple_bot
source venv/bin/activate
python simple_chatbot.py
```

---

## 🚀 Example Interaction

```
You: Hi
Bot: Hello! How can I assist you today?

You: I want to book a ticket
Bot: Sure! I can help you book a ticket. Where would you like to go?
```
